Politica de Privacidade

A Vencimento foi criada para ajudar profissionais a gerir horarios, turnos, remuneracao estimada, recibos, estatisticas, feriados, notificacoes e dados profissionais relacionados.

Dados tratados pela app

A app pode guardar dados introduzidos pelo utilizador, incluindo nome, profissao, local de trabalho, fotografia de perfil, turnos, ausencias, ferias, valores salariais, taxas de IRS, descontos, regras de suplementos, dados de segundo emprego, feriados municipais e informacao usada para estatisticas e simulacoes.

Armazenamento

Os dados sao guardados localmente no dispositivo do utilizador, usando armazenamento da propria app. A app nao vende dados pessoais e nao os envia para servidores proprios para criar perfis comerciais.

Permissoes do dispositivo

A app pode pedir acesso a funcionalidades do dispositivo, como fotografias para escolher uma imagem de perfil, calendario para sincronizacao de turnos, e notificacoes para alertas relacionados com horarios. Estas permissoes podem ser geridas nas definicoes do iOS.

Calculos e estimativas

Os valores apresentados pela app, incluindo vencimento, suplementos, horas extraordinarias, descontos, IRS, subsidios e estatisticas, sao estimativas baseadas nos dados configurados pelo utilizador. Estes resultados nao substituem recibos oficiais, informacao da entidade empregadora, aconselhamento contabilistico, fiscal ou juridico.

Partilha de dados

A app apenas partilha dados quando o utilizador usa uma funcionalidade de exportacao, partilha ou sincronizacao. Nesses casos, a informacao escolhida pelo utilizador pode ser tratada pela aplicacao ou servico de destino, de acordo com as respetivas politicas.

Servicos de terceiros

Se forem ativadas funcionalidades que dependam de servicos externos, como sincronizacao com calendario, compras na App Store, analitica, diagnostico de erros ou outros servicos do sistema Apple, esses servicos podem tratar dados segundo as suas proprias politicas.

Direitos do utilizador

O utilizador pode corrigir ou apagar dados diretamente na app sempre que a funcionalidade esteja disponivel. Tambem pode remover a app do dispositivo para apagar os dados locais associados, sujeito ao comportamento normal de copias de seguranca do iOS.

Contactos

Para questoes sobre privacidade, suporte ou pedidos relacionados com dados, contacta atraves da pagina de suporte.
