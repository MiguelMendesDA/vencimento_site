Porque isto importa

Quem faz turnos sabe que o recibo nunca é só salário base.

Vencimento nasce para reduzir contas manuais e dúvidas recorrentes: “quantas noites fiz?”, “quanto valeu este fim de semana?”, “a acumulação está certa?”, “o recibo bate certo com o meu horário?”. A app organiza estes dados para que cada utilizador consiga acompanhar o mês com mais confiança.
